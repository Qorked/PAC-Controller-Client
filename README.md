# PAC Controller

Xbox and PlayStation controller support for Pokémon Auto Chess, plus a Friends list with an ELO leaderboard and one-click spectating.

**[⬇ Download the latest version](https://github.com/Qorked/PAC-Controller-Client/releases/latest)**

Unofficial fan tool. Pokémon Auto Chess belongs to its developers; this isn't made or endorsed by them.

## Which file do I need?

| You use | Download |
|---|---|
| Windows, no install | `PAC-Controller-Client-…-windows-x64-portable.exe` |
| Windows, installed with a Start menu entry | `PAC-Controller-Client-…-windows-x64-setup.exe` |
| Chrome or Edge (any OS) | `PAC-Controller-…-chrome-extension.zip` |
| Firefox | `PAC-Controller-…-firefox-addon.zip` |

**Signing in with Google?** Use the Chrome/Edge extension. Google blocks sign-in inside desktop apps, so the Windows app only works with email or Twitter accounts.

## Install

### Windows app
- **Portable:** double-click the `.exe`. Nothing to install.
- **Setup:** run the setup `.exe` and follow the steps.
- Windows may say "Windows protected your PC" because the app isn't code-signed: click **More info → Run anyway**.

### Chrome or Edge extension
1. Unzip the extension into a folder you'll keep (the browser loads it from there).
2. Open `chrome://extensions` (Edge: `edge://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.
4. Open the game in your browser.

Tip: in Chrome, **⋮ → Cast, save and share → Install page as app** gives the game its own window.

### Firefox
1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…** and pick the zip.
3. Firefox removes it when it closes, so load it again next time.

## Using it

- Plug in an Xbox or PlayStation controller and press any button. Button prompts show what each button does.
- **Menu / Options** opens the quick menu: Friends, Emote, Wiki, Meta report, Team planner, Options, Leave game and the controller guide.
- **No controller?** F2 opens the same menu and Ctrl+Shift+F opens Friends.
- **Friends:** in the lobby, open the Leaderboard panel's **Friends** tab. Add people by name, or swap friend codes with **My friend code**. Friends who are in a game get a Spectate button.
- **In a game:** LB/RB cycle the board, items, shop and players. In the players list they flip through boards, and B brings your own board back.
